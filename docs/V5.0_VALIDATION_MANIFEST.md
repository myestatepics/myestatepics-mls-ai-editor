# V5.0 One-Chance Visual Validation Manifest

## Purpose

V5.0 is a single-candidate comparison against the exact V4.0 golden baseline
(`e3f6d850cec7091149536f2a6b47236053afdc95`, tag `v4.0`). It is not approved
as visually superior until the Product Owner completes this review.

## Fixed comparison

For each image below, compare the V4.0 AFTER result (Column A) with the V5.0
AFTER result (Column B). The whole photograph must be at least as good as
V4.0; a floor-only improvement does not compensate for a window, material,
cabinet, exterior, or exposure regression.

| Locked source | Required checks |
| --- | --- |
| Newgard #5 | Hardwood reflection, large-window exterior, interior brightness, material color |
| Newgard #11 | Dark hardwood, directional light, large room, window pull, natural floor appearance |
| Newgard #24 | Hardwood foreground and flare, sliding-door daylight, white cabinetry, gray island, exterior view, kitchen balance |
| Newgard #33 | Darker-room exposure, window behavior, hardwood, depth, no change outside the affected floor area |

## Acceptance gates

- V4.0 window pull, exterior clarity, accepted blue treatment, and sky behavior
  must be retained.
- White cabinets remain neutral white; gray island remains gray; hardwood
  remains its original brown color.
- Directional light, natural hardwood sheen, grain, plank boundaries, texture,
  soft reflections, and photographic depth remain present.
- Reduce only abnormally intense, visually dominant, window-driven hardwood
  glare. Do not flatten, recolor, uniformly smooth, or alter unaffected floor.
- No extra paid API request is permitted: each successful image uses one direct
  `gpt-image-2` Images Edit request.

## Decision

The Product Owner alone performs one paid validation run using exactly these
four images. If any complete-photo comparison regresses materially, reject
V5.0 and keep V4.0 as production. Do not create a second V5 candidate or make
an unapproved paid validation call.
