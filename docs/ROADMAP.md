# Roadmap

Roadmap items are proposals, not committed features. Priority may change after
production evidence and commercial requirements are reviewed.

## Current status

Production v2.1 RC1 provides a portable macOS batch GUI, external production
prompt, architectural safeguards, Demo Mode, deterministic verification,
review routing, CSV/SQLite records, and repeatable app/DMG builds.

## Completed

- legacy v1.6 behavior baseline
- single-file production application
- Low/Medium quality and selected-file processing
- project and packaged API-key handling
- isolated no-cost Demo Mode
- external prompt and architectural fidelity hardening
- current-output-based reprocessing eligibility
- production-oriented GUI workflow
- portable macOS app and DMG build
- automatic selection startup regression fix

## Near-term

1. Build a curated regression library with consented, non-sensitive fixtures.
2. Add packaged GUI integration tests for selection and first-run key handling.
3. Create a custom `.icns` and validate Dock/Finder presentation.
4. Profile startup, image analysis, encoding, and batch throughput.
5. Define support diagnostics and reproducible issue-report templates.

## Mid-term

- batch history browsing and export
- performance improvements and bounded parallel preparation where safe
- usage analytics and cost reporting with explicit privacy requirements
- signed and notarized universal macOS distribution
- automated release checksums and GitHub prerelease workflow
- expanded mirror, window, mixed-light, and material regression coverage

## Long-term

- Pixlmob production readiness assessment and delivery integration
- commercial release, licensing, update distribution, and support model
- role-based operational workflows if multi-user demand is validated
- configurable approved profiles without weakening architectural fidelity

Commercial work must preserve source truth, explicit cost control, reviewability,
and secret/data handling standards.
