## Processing contract

- Model: `gpt-image-2.5-sunburst`
- User-selected qualities: `medium`, `high`
- Maximum Images Edit attempts per image: 1
- Production prompt SHA-256: `065b48e3d0a42fb6dc7a7e13381323859efd0af16b778d1aa0fd00ebce5f4598`
- No generation mask; no Python upscaling; native API dimensions are retained.
- Premium Finish runs once: UnsharpMask radius 0.45, percent 12, threshold 12;
  blended 88% native image and 12% sharpened image.
- JPEG preserves the filename, native dimensions, quality 100, 4:4:4, and 300 DPI metadata.
- All successful JPEGs remain in one configured output folder.

PASS, REVIEW, and ERROR are Python triage states only. REVIEW items are
prioritized in Review Results for human before/after inspection; they are not
rejected or moved. Analyze was removed from the UI; internal scan refresh remains.
